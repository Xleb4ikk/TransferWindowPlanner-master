# 🚀 Transfer Window Planner

Планировщик межпланетных перелётов с расчётом траекторий и AI-конструктором ракет.

## 📦 Быстрый старт

### Для новых пользователей (автоматическая установка):

1. **Двойной клик** на файл `START.bat`
2. Программа автоматически проверит зависимости и запустится
3. Если .NET SDK не установлен - откроется страница загрузки

### Альтернативный запуск:

**Windows PowerShell:**
```powershell
.\Launch.ps1
```

**Через существующий скрипт:**
```powershell
.\launch_rocket_builder.ps1
```

## 🛠️ Требования

- **Windows 10/11** (рекомендуется)
- **.NET 10 SDK** (устанавливается автоматически)
- **4 GB RAM** минимум
- **Python 3.8+** (для AI-конструктора ракет, опционально)

## 📚 Основные функции

### 1. Расчёт траекторий (Transfer Planner)
- **Single Transfer** - расчёт одной траектории
- **Porkchop Plot** - построение карты оптимальных окон запуска
- Поддержка планет от Меркурия до Нептуна
- JPL данные орбит
- Расчёт Delta-V для манёвров

### 2. AI Rocket Builder
- Автоматический дизайн многоступенчатых ракет
- ML-модели для оптимизации конструкции
- Подбор двигателей и топливных баков
- Расчёт массы и Delta-V

### 3. Визуализация
- Delta-V диаграммы
- Вид солнечной системы
- Экспорт в JSON/CSV

## 🎯 Примеры использования

### Базовый расчёт Earth → Mars

1. Запустить `START.bat`
2. Выбрать Origin: **Earth**
3. Выбрать Destination: **Mars**
4. Указать дату отлёта (например: 2026-08-15)
5. Нажать **"Run"**
6. Результаты появятся во вкладках Summary/JSON

### Porkchop Plot

1. Загрузить **"Porkchop Template"**
2. Указать диапазон дат (Window Start/End)
3. Настроить шаги сетки
4. Запустить расчёт
5. Получить карту оптимальных окон запуска

### AI Rocket Builder

1. Нажать кнопку **"Rocket Builder AI"**
2. Ввести параметры миссии (Delta-V, масса полезной нагрузки)
3. Выбрать ML модель
4. Получить оптимизированную конструкцию ракеты
