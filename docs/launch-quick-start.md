# Быстрый старт - Калькулятор подъёма на орбиту

## Включение расчётов

Добавьте секцию `launch` в JSON конфигурацию:

```json
{
  "request": {
    "origin": "Kerbin",
    "destination": "Mun",
    "departureParkingOrbitAltitude": 70000,
    "launch": {
      "enabled": true
    }
  }
}
```

## Полная конфигурация с объяснениями

```json
{
  "launch": {
    "enabled": true,                    // Включить расчёты
    "rocketInitialMass": 500000,       // Начальная масса (кг) - Falcon 9
    "rocketThrust": 7000000,           // Тяга (Н) - Merlin engines
    "rocketIsp": 310,                  // Удельный импульс (сек) - vacuum ISP
    "launchLatitude": 0,               // Широта запуска (градусы)
    "targetInclination": 0,            // Наклонение целевой орбиты (градусы)
    "planetRotationPeriod": 86164      // Период вращения планеты (сек)
  }
}
```

## Как запустить программу

```bash
# Один раз установить
dotnet build

# Запустить расчёты
dotnet run -- .\examples\scenarios\launch\kerbin-to-mun-with-launch.json
```

## Какая информация выводится

Программа выводит:
1. **Время выведения** - Сколько секунд до выхода на орбиту
2. **Итоговые параметры** - Высота и скорость
3. **Дельта-V эффективность**:
   - Кинематический ΔV - минимально требуемый (идеальный)
   - Фактический ΔV - сколько реально затрачено
   - Гравитационные потери - потеря энергии на работу против гравитации
4. **Процент эффективности** - Отношение идеального к реальному

## Интерпретация результатов

### Если орбита достигнута
```
✓ УСПЕШНО
Время выведения: 345.2 сек (5.8 мин)
```
Ракета успешно вывела грузы на нужную орбиту за указанное время.

### Если орбита НЕ достигнута
```
✗ НЕУДАЧНО - не достигнута орбита
Достигнутая высота: 45.23 км
```
Ракета не хватило топлива или тяги. Нужно увеличить параметры.

## Гравитационные потери

Это часть дельта-V, потраченная на работу против гравитации:

- **Высокие потери (>30%)** - ракета летит вертикально слишком долго
- **Нормальные потери (20-30%)** - правильно организован гравитационный поворот
- **Низкие потери (<20%)** - очень эффективный запуск (редко встречается)

**Формула**: `Процент потерь = Гравитационные потери / Фактический ΔV × 100%`

## Где взять реальные параметры ракет

### Для RealSolar System (RSS):
- Земля: `planetRotationPeriod: 86164`
- `launchLatitude: 28.4` (Cape Canaveral)

### Для других модов КСП:
- Смотрите `bodies.cfg` в папке мода
- Период вращения = `rotationPeriod` / 360° (переводите в секунды)

## Лайфхаки

1. **Для точки старта на экваторе**: `launchLatitude: 0`
2. **Для полуарктического старта** (как Плесецк): `launchLatitude: 62.5`
3. **Для экономии дельта-V**: Запускайтесь с экватора (`launchLatitude: 0`)
4. **Для увеличения тяги**: TWR > 1.3 хорошо, TWR > 2.0 означает избыток

## Проверка правильности параметров

Типичные значения TWR (Thrust-to-Weight Ratio) при старте:

```
TWR = Thrust / (InitialMass × g)
Где g на земле = 9.80665 м/с²

Falcon 9: TWR ≈ 1.35-1.4
Saturn V: TWR ≈ 1.15
SLS: TWR ≈ 2.0
```

Низкий TWR (<1.1) - ракета не сможет взлететь
Высокий TWR (>2.5) - слишком много потерь на структуру
